

## 🎯 **WHAT'S IN THE MODELS FOLDER:**

The `models/` folder is your **centralized repository** for all trained machine learning models, scalers, analysis results, and visualizations. Here's what each category contains:

---

## 🤖 **1. TRAINED MODEL FILES (.pkl)**

### **🔴 Anomaly Detection Models:**
- `severity_score_GradientBoosting.pkl` - Individual Gradient Boosting model for severity scores
- `severity_stacking_model_v2.pkl` - **MAIN** Stacking ensemble for severity score prediction (0-1)

### **🟡 Severity Stage Classification Models:**
- `severity_stage_gb_model_v1.pkl` - Gradient Boosting for stage classification
- `severity_stage_rf_model_v1.pkl` - Random Forest for stage classification  
- `severity_stage_stacking_model_v1.pkl` - **MAIN** Stacking ensemble for stage prediction (0-4)

### **🟢 TTF (Time-to-Failure) Prediction Models:**
- `best_ttf_model_gradient_boosting.pkl` - **MAIN** Best TTF model (84.22% R²)
- `Random_Forest_TTF_km.pkl` - Baseline Random Forest for TTF_km
- `Random_Forest_TTF_years.pkl` - Baseline Random Forest for TTF_years
- `Ridge_Regression_TTF_km.pkl` - Baseline Ridge Regression for TTF_km
- `Ridge_Regression_TTF_years.pkl` - Baseline Ridge Regression for TTF_years

### **📁 all_models/ Subdirectory:**
- `ttf_gradient_boosting.pkl` - Individual TTF Gradient Boosting
- `ttf_random_forest.pkl` - Individual TTF Random Forest
- `ttf_ridge_regression.pkl` - Individual TTF Ridge Regression
- `ttf_stacking_ensemble.pkl` - TTF Stacking ensemble

---
